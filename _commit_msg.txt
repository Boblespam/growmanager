docs(wiki): documente la panne credentials update.sh sur le serveur prod

update.sh ne passe pas --env-file .env.production, Compose ne charge
que .env : le backend recree recuperait des identifiants MySQL par
defaut au lieu des vrais, alors que le conteneur db (jamais redemarre
par update.sh) garde le vrai mot de passe. Panne survenue le
2026-09-12 juste apres un update.sh latest.

Resolu en prod : mot de passe root MySQL retrouve via docker inspect
(env vars figees a la creation du conteneur), compte grow realigne
sur .env.production, puis ln -sf .env.production .env sur le serveur
pour que docker compose charge les bonnes variables automatiquement.
